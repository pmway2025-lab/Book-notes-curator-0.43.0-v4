# 17 涵構與設計姿態：配合，還是反襯？

> **語料來源**：使用者提供之五張書頁翻拍（2026-09-05 匯入），為某建築教科書中譯本
> 的「涵構（context）」章節與圖示方法章節（可辨頁碼約 26–27）。
> **與 `14` 極可能是同一本書的不同章節**（版面、筆法、術語一致），但翻拍頁未含書名頁，
> **不臆測書名**。
>
> **性質**：第三方著作 → 依 `10` 的增補規範節，**只收概念架構與方法，
> 不轉錄原文段落、不重製圖面**。
>
> **這一檔補的是 `14` 雙列矩陣「下排」缺的那條軸**：知道要回應，
> 但**回應可以有兩種相反的姿態**，而模型原本沒有這個選項。

## 一、涵構＝「交織編組在一起」

原語料從字義切入：**涵構（context）**在辭典中指「整體狀況、背景，
或關乎某些事件或事務的環境」，而該字的衍生意義是「**交織編組在一起**」。

**這個字義決定了整個方法的性質**：

| 若把基地讀成 | 分析的目的變成 |
|---|---|
| 一塊待開發的空地 | 描述現況、清點限制 |
| **一塊已經交織成形的布料** | **把設計編織進去** |

**建築物是基地的「外來者」**——原語料用的正是這個詞。
設計的工作是**在外來者與基地之間爭取某種「妥適」**。

**關鍵的一句限定**：妥適**並不必然意味建築物從屬於基地**。
這一句把「尊重基地」從教條變回選項——**順從只是其中一種姿態。**

> 對照 `12`：`12` 指出「基地」一詞已預設人類目的；本檔補上另一半——
> **既然預設了目的，就要誠實面對「我是外來者」，並明說我打算怎麼對待這塊布料。**

---

## 二、兩種姿態：配合 vs 反襯

這是本檔最有用的一組概念，**直接補進 `14` 雙列矩陣的下排**：

| 姿態 | 做什麼 | 什麼時候用 |
|---|---|---|
| **配合**（fit） | 讓建築物與基地既有條件取得一致 | 既有紋理有價值、涵構強勢、需要延續 |
| **反襯**（contrast） | 讓建築物與基地既有條件形成對比 | 既有條件貧乏或負面、需要標示新的角色、要建立地標 |

**兩者都是正當的設計決策，不是好壞之分。**
原語料強調：**無論是配合還是反襯，早期思考都具關鍵性**——
**姿態要在概念階段就選定並說清楚，不能事後補述。**

**判準三問**：

1. **這塊基地的既有條件值得延續嗎？** 值得 → 偏配合；貧乏或負面 → 反襯有正當性。
2. **這棟建築要扮演什麼角色？** 融入背景 → 配合；擔任門戶或地標 → 反襯。
3. **反襯有沒有付出代價的準備？** 反襯必然引起注意，**也必然引起反對**；
   沒有想清楚就反襯，會被讀成不尊重而非有意識的選擇。

## 三、九個處置動詞：把「回應」講具體

原語料把設計者對基地條件的處置分成兩組。**這是 `14` 下排的動詞表**——
與其寫「回應噪音」，不如寫清楚你要對它做什麼：

**A 組：認可並延續（偏配合）**

| 動詞 | 意思 |
|---|---|
| **保存** | 原樣留下，不動 |
| **強化** | 讓它更明顯、更有效 |
| **擴大** | 延伸它的範圍或影響 |
| **改善** | 保留其性質但提升品質 |

**B 組：改變或抵銷（偏反襯）**

| 動詞 | 意思 |
|---|---|
| **變動** | 審慎地調整它 |
| **淘汰** | 移除 |
| **掩藏** | 遮蔽視線但不移除 |
| **偽裝** | 使其不被辨識 |
| **改造** | 改變其性質與用途 |

**兩條使用紀律**：

1. **每個基地條件都要被指派一個動詞**。沒有被指派的條件，
   代表你還沒決定要拿它怎麼辦——**這就是 `14` 雙列矩陣裡的空格。**
2. **B 組的動詞要寫出理由**。淘汰一棵樹、掩藏一道牆都是可以的，
   但**「審慎而深思地作這些決策」是原語料的原則**：
   決策可以強硬，過程不能隨意。

> **接回 `12` 的不可逆性**：B 組裡「淘汰」與「改造」常常不可逆。
> **不可逆的處置要走 `12` 的門檻條件，不能只當成成本項。**

## 四、三元關係：建築物 × 使用者 × 涵構

原語料以一張三角關係圖呈現設計的三個節點，各自帶著一組要素：

| 節點 | 包含的要素（示例性質） |
|---|---|
| **建築物** | 照明、構造、樓板、牆、天花板、機械設備、色彩 |
| **使用者** | 屋主、工作者、警衛、顧客、路過的人、房客 |
| **涵構** | 地點、地形、排水、地界、樹、人行道 |

**三者兩兩相連，設計是在三者之間求協調。**

**這補上本 skill 的一個結構性缺口**：模型原本只有「空間」與「回應」，
**使用者只以零散形式存在**（`05` 的需求端偏好、`04` 的利害關係人）。
本節把使用者提升為**與基地同級的節點**。

**兩個實用推論**：

1. **使用者不只是業主**。清單裡包含「路過的人」「警衛」「房客」——
   **不出錢但每天使用的人，也是使用者**。他們的需求常常決定案子好不好用，
   卻最容易在需求訪談中缺席。
2. **三角形的任一邊都可能是矛盾的來源**。建築物×涵構的矛盾是形式問題，
   建築物×使用者是機能問題，**使用者×涵構是最容易被忽略的一邊**——
   使用者的行為與既有環境的衝突（如既有捷徑被新配置切斷）。

## 五、剖面：本 skill 一直缺的那個維度

原語料明確要求：**基地設計、營建與空間配置，平面與剖面的課題要同時包含。**

並列出剖面才看得出來的關係：

- 各個樓地板面與**地形輪廓**的關係
- 各個空間的**高度與視野**的關係
- 從高處**步行而下**的空間序列
- 空間的**堆積**與外形的關係
- 與鄰近環境的**尺度**關係

**原語料的結論很直接**：研究基地分區的**斷面**是利器，就如同分析處理平面一樣。

> **這是對本 skill 的一記提醒**：`09` 的八要素、`14` 的雙列矩陣、
> `15` 的軸線分析——**幾乎全是平面思維**。
> **高差、視野高度、空間序列、量體堆疊，只有剖面看得出來。**
> 從 Gen 1.13 起，凡涉及地形高差、視野、量體關係的分析，**應同時畫剖面**。

### 建築物置於特定位置的理由（清單）

原語料列出的考量，可直接當成配置決策的檢核：

| # | 理由 | 對應鏡 |
|---|---|---|
| 1 | 土壤承載狀況 | 山川（地質） |
| 2 | 縮減營建期間土木工事的外圍輪廓 | 經濟（成本）＋施工 |
| 3 | 享受視野與和風的位置 | 天時＋視野三分法（`14`） |
| 4 | 對街道與街角有良好的能見度 | 「對基地的視野」 |
| 5 | 鄰近可提供便利服務的巷弄 | 物流（服務動線） |
| 6 | 利用已崩毀的斷崖等既存痕跡（收納營建產生的擾動） | 山川＋不可逆性 |
| 7 | 迴避應被保存而特別有價值的東西 | `12` 不可逆 |
| 8 | 迴避特別不利的情況（不良視野或噪音） | 視野＋噪音 |

**第 2 與第 6 項特別值得注意**：兩者都是**用配置去降低施工的擾動**——
把新建物放在已經被破壞過的地方，而不是動到完好的部分。
**這是施工思維進入配置決策的實例**，呼應 `09` 的施工期動線。

## 六、環境涵構分析的六級尺度

原語料指出涵構分析可應用於**任何尺度**，並列出六級：

```
地區 → 城市 → 鄰近環境 → 土地 → 建築物 → 空間
```

**用法**：分析時明確標出自己在哪一級，**並至少往上、往下各看一級**。
只看單一尺度，會漏掉上位條件與內部後果。

> **接回 `06` 步驟①與 `07`**：`06` 要求界定尺度，本節給出可用的分級；
> `07` 的跨域轉譯也可用這六級對位。**同一份分析在不同尺度會得到不同結論，
> 這不是矛盾，是尺度不同。**

## 七、圖示的四個步驟

原語料把「怎麼畫分析圖」拆成四步，補上 `09` 圖例規範缺的**製作流程**：

| 步 | 做什麼 | 常見失敗 |
|---|---|---|
| ① **設計圖象形式** | 為每個關鍵論點想一個圖形符號 | 直接抄別人的符號，與內容不合 |
| ② **精煉及簡化** | 把符號簡化到最少筆畫仍可辨識 | 畫太細，反而看不出重點 |
| ③ **強化重要的圖形資訊** | 用粗細、深淺、大小拉出層級 | 全部一樣重，等於沒有重點 |
| ④ **標示及註解** | 加上文字說明與圖例 | 只有圖沒有字，讀者各自解讀 |

### 兩種圖形化策略：合成 vs 分散

原語料明白列出兩種把資料圖形化的方法，**各有代價**：

| 策略 | 做法 | 強項 | 代價 |
|---|---|---|---|
| **合成（調整及合成）** | 把所有基地資料畫在**同一張圖**上 | 強調**整體情況**，看得出**各構成元素之間的關係** | **容易變得太雜亂、太複雜**——基地越複雜越嚴重 |
| **分散（隔離）** | 每一項資料各畫一張**簡化的圖說**，同一個基底不斷重複 | 每個因子**能被單獨檢查與單獨回應** | 張數多；**關係要靠讀者自己拼** |

**分散式的原則**：**開放式的指引圖著重在每一個關鍵論點分開表達**，
使每一個單一事實（因子）個別容易理解。
**要表現多少資料，就畫多少次。**

> **這正是 `14` 雙列矩陣「一格一事」的理論依據。**
> 一張把所有資訊疊在一起的綜合圖，看起來完整，
> 但**沒有任何一項能被單獨討論**。

**用合成式時的兩條保命規則**（原語料的提醒）：

1. **縮小比例**以避免圖面雜亂——合成圖不是把每張圖等比疊上去。
2. **保持清晰的層次**：**確保主要的基地課題被主要的圖形強調出來**。
   合成圖若沒有層次，就只是把混亂集中在一張紙上。

**取捨判準**：**要看關係，用合成；要逐項討論與回應，用分散。**
實務上兩者並用——**分散式當工作底稿（每項單獨檢查），合成式當溝通成果
（呈現整體與關係）**，這也對應 `16` 第八節「報告可查核、圖板可說服」的分工。

### 精緻度由用途與讀者決定

原語料開宗明義的一句：**資料要畫得多精簡，端視這些圖表的作用與呈現的對象而定。**

**這是一條反對「越精緻越好」的紀律**：

| 圖的用途 | 該有的精緻度 |
|---|---|
| 自己現勘的工作底稿 | 潦草可以，**只要自己看得懂、能標註** |
| 內部討論 | 中等——**重點清楚即可，不必上色描邊** |
| 對外簡報、送審、競圖 | 精緻——**因為它同時在傳達「這件事被認真對待」** |

**判準**：畫圖的時間是成本。**在工作底稿上追求精緻，是把成本花在沒有人會看的地方。**

### 圖形化的流程

原語料同時給出一條上位流程，與本節第七小節的四步驟互相對應：

```
收集 → 圖象化 → 精減化 → 圖說
```

**「精減化」是關鍵的一步**：資料收集完不能直接畫，
**要先決定哪些留、哪些丟**。跳過這一步，畫出來的就是資料的複印，不是分析。

## 八、涵構分析在整條流程上的位置

原語料描述的因果鏈是：

```
涵構分析 → 建立信心 → 喚起設計語彙 → 產生基地課題 → 促發設計回應意象
```

**兩點值得記下**：

1. **「建立信心」被明白寫成一個環節**。一份徹底的涵構分析的作用之一，
   是讓設計者**敢下決定**——這與 `12` 說的「框架防漏但不生創意」是一組：
   分析不產生創意，但**分析消除猶豫**。
2. **課題在語彙之後**。順序是先有語彙被喚起，才形成課題——
   與 `16` 的「課題是分析的收斂點」互補：
   **`16` 講課題怎麼寫，本檔講課題從哪裡冒出來。**
