# 16 課題化、設計準則與行動分期：從分析走到管制

> **語料來源**：使用者提供之單張都市設計競圖圖板（A0 直式，作品編號 A021，
> 2026-09-05 匯入）。標的為某科技園區區段徵收範圍的都市設計提案。
>
> **性質**：第三方設計作品 → 依 `10` I 節規範，**只收方法、版面架構與條文形式，
> 不轉錄其具體策略、數值與圖面**。個案的準則數值屬該案設計決定，不入庫。
>
> **這一檔補的是分析的下游三段**：`09` 查完 → `14` 轉成設計回應 → `15` 寫成報告，
> 但**課題怎麼收斂、設計意圖怎麼變成可執行的規則、方案怎麼排進時間**，仍是空白。

---

## 一、課題的「A × B」對立命名法（本檔最有用的一段）

`15` 的第六章把調查收斂成「潛力與限制」兩欄。本語料再往上收斂一層：
**把整個基地的問題壓成三組張力**，每組用 `A × B` 命名。

觀察到的定式：

```
課題名稱：  舊有紋理  ×  新建紋理
配一張圖：  只畫出這一組張力的空間分布，其餘全部略去
一段說明：  張力從何而來、造成什麼具體後果
```

**三條可遷移的判準**：

1. **課題是張力，不是缺點**。「排水不良」是缺點，「**自然生態 × 都市建成**」才是課題——
   後者指出兩種價值同時存在且互相擠壓，**設計的工作是調解，不是消滅其中一方**。
2. **一張圖只畫一組張力**。課題圖不是現況圖：**把與該張力無關的資訊全部拿掉**，
   讀者才看得出那組矛盾。
3. **三組左右為宜**。壓到三組是強迫取捨——**留下來的就是這個案子真正在解的問題**。
   十項課題等於沒有課題。

> **與 `15` 的關係**：`15` 第六章的潛力／限制是**逐項的**，本節的課題是**收斂的**。
> 順序是：三大類清單（`09`）→ 潛力與限制（`15`）→ 三組課題（本節）。
> **每一層都在減少項目、增加判斷。**

## 二、主題三軸：貫穿全案的一致性骨架

本語料選定三個主題（例如智慧／生態／社區之類的三分），並讓**同一組主題
從頭貫穿到尾**：

| 環節 | 三軸如何出現 |
|---|---|
| 設計構想 | 每軸各一張策略圖與圖例 |
| 設計準則 | 每軸各一組條文 |
| 行動方案 | 每軸各一列，橫向切短／中／長期 |

**為什麼有效**：一份提案最常見的失敗是**前後段各講各的**——構想講願景、
準則講法規、行動方案講時程，三者沒有對應關係。
**用同一組主題當骨架，讀者可以縱向追蹤任何一軸從構想到落地的完整路徑。**

**操作判準**：訂主題時問一句——**每一軸都能一路寫到行動方案嗎？**
寫不下去的主題，就只是口號。

## 三、手法的跨主題標籤：一個效率判準

本語料的每個設計手法底下都標了它服務的目標，形如
`交通旅遊 × 環境生態 × 安全防災 × 健康生活`。

**這不是裝飾，是效率的顯示器**：

| 標籤數 | 判讀 |
|---|---|
| 一個手法標 3～4 個目標 | **高槓桿**：一件事解決多個問題，優先做 |
| 只標 1 個目標 | 單點解，成本要嚴格檢視 |
| 標了但說不出怎麼服務 | **虛標**——最常見的問題 |

**用法**：把所有手法列表，標上各自服務的目標，**依標籤數排序**。
資源有限時，先做跨目標的那幾個。

> 這條與 `03` 的樞紐六判準「交會度」同構：**在多條軸線交會處下手，效益最大。**

## 四、設計準則：分析→設計→管制的最後一環

這是本語料補得最徹底、也是本 skill 原本完全沒有的一層。

前面所有檔案的產出都停在「**這個案子應該怎麼做**」；設計準則則是
「**任何人在這裡蓋房子都必須怎麼做**」——**從個案決定變成通則管制**。

### 條文的定式

```
【觸發門檻】+【應為義務】+【量化標準】
例：建築面積達 ＿＿ 平方公尺以上者，屋頂應設置 ＿＿% 以上的 ＿＿設施。
```

三個構件缺一不可：

| 構件 | 作用 | 缺了會怎樣 |
|---|---|---|
| **觸發門檻** | 界定誰要遵守（規模、位置、用途） | 全部適用 → 小案被過度負擔，反彈到無法執行 |
| **應為義務** | 明確的作為，不是期待 | 寫成「宜」「鼓勵」→ 等於沒有 |
| **量化標準** | 可查核的數字或做法 | 「應注意景觀」→ 無法認定是否達成 |

### 三種準則的性質差異

| 類型 | 例（形式，非個案數值） | 特性 |
|---|---|---|
| **設施型** | 達某規模者應設置某比例的某設施 | 最好查核，爭議最少 |
| **空間型** | 沿某街廓退縮若干公尺並設置特定鋪面 | 影響配置，需與法定退縮併看 |
| **性能型** | 照明以不干擾生態為原則，採低亮度設計 | **最難認定**，必須補上可量測的指標，否則形同宣示 |

**判準**：性能型準則若沒有配套的量測方法，**寫了也管不到**。
要嘛補指標，要嘛改寫成設施型或空間型。

> **接回 `04` 政治鏡**：設計準則就是「區劃」在基地與街廓尺度的版本。
> `04` 說區劃反映的是「中央在怕什麼」；同理，**看一份設計準則管制了什麼，
> 就知道規劃者最擔心哪一件事失控。**

## 五、行動方案：時期 × 主題的矩陣

本語料把行動方案畫成矩陣：**橫軸為短／中／長期，縱軸為主題三軸**，
每格填具體項目，並各配一段說明總結該期的目標。

**三個設計要點**：

1. **每期都要有完整的三軸**，不是「短期做硬體、長期做軟體」——
   那等於承認前期是半成品。
2. **短期項目必須是「不依賴他人也做得到」的**。若短期就要等鄰地開發、
   等法規修正，這份時程只是願望。
3. **長期項目允許依賴外部條件**（如上位交通建設完工），
   但**要明寫依賴什麼**，否則無法追蹤是否還成立。

> **接回 `04` 的時間三來源與 `15` 第二節**：周邊建設有排程、法規有期限、
> 自己的方案也有分期。**三條時間軸要疊在同一張表上看**，
> 才知道哪一期的假設會被外部變化推翻。

## 六、圖板的敘事順序：版面即論證結構

一張圖板的排版不是美編，是**論證的順序**。本語料的順序可以直接沿用：

```
① 一句話概念（含隱喻）        ← 讀者三秒內知道你在講什麼
② 基地現況（選址・周邊・交通・定位）
③ 基地分析與課題（三組 A×B）  ← 分析的收斂點
④ 規劃目標（一張總圖）
⑤ 設計構想（三軸各一張）      ← 開始給答案
⑥ 總配置圖 ＋ 手法圖（帶跨主題標籤）
⑦ 設計準則（三軸各一組條文）  ← 從個案走向通則
⑧ 實際手法（技術架構關係圖）
⑨ 行動方案（時期 × 主題矩陣）  ← 落到時間
```

**兩個觀察**：

- **③ 是全板的樞紐**：前面都是事實，後面都是回應。**課題定錯，後面全部失焦。**
- **概念隱喻（①）的作用是統攝**：用一個具體意象把三軸綁在一起，讓提案被記得。
  **但隱喻不能代替論證**——若拿掉隱喻後三軸仍然成立，它是好隱喻；
  若拿掉就散架，那是靠比喻撐場。

## 七、三個誤用警告

1. **不要把課題寫成問題清單**。`A × B` 的價值在於指出**兩個都要的東西在打架**；
   寫成「缺乏綠地、動線混亂、紋理破碎」就退回成清單，失去收斂的意義。
2. **不要用主題軸包裝既有做法**。先想好手法再回頭貼三軸標籤，
   是本節第三段講的「虛標」。**檢查法：把主題軸拿掉，這個手法還存在嗎？
   若照樣存在，它就不是從主題推導出來的。**
3. **設計準則不是願望清單**。沒有觸發門檻、沒有量化標準的條文，
   在實際審查時一律無法執行。**寫不出數字，就承認它是設計說明而不是準則。**

## 八、兩種成果形式的分工

至此本 skill 收錄了兩種基地分析的成果形式，**用途不同，不可互相取代**：

| | `15` 報告章節 | `16` 圖板 |
|---|---|---|
| 形式 | 文字為主、逐章展開 | 圖為主、單張全覽 |
| 讀者 | 業主、審查單位、後續設計者 | 評審、公眾、決策者 |
| 強項 | **可查核**：每項調查都留下紀錄 | **可說服**：三秒抓住重點 |
| 弱項 | 不易看出全局關係 | 過程被壓縮，難以回溯 |
| 收斂程度 | 逐項（潛力／限制） | 高度收斂（三組課題） |

**實務建議**：**兩者都要有**。報告是底稿與證據，圖板是決策與溝通介面。
只有圖板，日後無法回答「這個結論怎麼來的」；只有報告，沒人看得完。
