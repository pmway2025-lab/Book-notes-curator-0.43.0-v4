# 11 九地：相對態勢的九種型態

> **語料來源**：使用者提供之對話紀錄中引用的《孫子兵法・九地篇》原文與白話譯文
> （2026-09-05 匯入）。本檔為概念架構的整理與操作化，**原文不在此重述**——
> 孫子為公有領域典籍，需要原文請直接查閱《孫子兵法》。

## 一、九地與《布局天下》的分工（為什麼要另立一檔）

兩者不是同一個東西，**放在同一層會互相打架**：

| | 《布局天下》四角四邊 | 《孫子》九地 |
|---|---|---|
| 回答什麼 | **這塊地在版圖上是什麼位置** | **我此刻在這塊地上是什麼處境** |
| 性質 | **絕對區位**：地形決定，長期不變 | **相對態勢**：由我與對手的相對位置決定 |
| 會不會變 | 幾百年不變 | **同一塊地，換個立場就換一種地** |
| 對應鏡 | 山川鏡＋政治鏡 | 軍事鏡（軸線與處境） |
| 用來做什麼 | 選重心、判要地價值 | **決定此刻該採取哪一種行動** |

**關鍵區別**：關中永遠是關中；但同一塊土地，對本地人是散地、對入侵者是輕地或重地。
**九地不是地形分類，是處境分類。** 這是它能補進五鏡的理由——
五鏡告訴你這塊地值多少，九地告訴你**你現在站在什麼位置上，該怎麼動**。

## 二、九型與處置原則

| 地型 | 定義（處境） | 孫子的處置 | 處置的邏輯 |
|---|---|---|---|
| **散地** | 在自己的地盤上作戰 | 無戰 | 士卒思歸、易散；**主場不代表優勢**，不宜在此決戰 |
| **輕地** | 剛進入對方地界不深 | 無止 | 進退兩可、立足未穩，**不要停留**，快速通過或推進 |
| **爭地** | 我得利、對方也得利 | 無攻 | **雙方都想要的地方，硬攻代價最大**；先到、迂迴或交換，不強攻 |
| **交地** | 雙方都能自由往來 | 無絕 | 通路開放，**重點在不被切斷聯絡**，維持補給與退路 |
| **衢地** | 多方交界，先到者得援 | 合交 | **價值在外交不在武力**，先取得第三方支持 |
| **重地** | 深入對方腹地 | 掠 | 補給線太長，**必須就地取得資源**，否則自然萎縮 |
| **圮地** | 山林險阻沼澤，難行 | 行 | **不要停、不要駐**，行軍地不是決戰地 |
| **圍地** | 入口狹窄、退路迂遠 | 謀 | 力量無法展開，**只能靠計謀**，不能靠硬拚 |
| **死地** | 不速戰則亡 | 戰 | 已無選擇，**猶豫本身是最大的成本** |

> 註：原文有「圮地」與「泛地」兩種寫法（使用者提供的文本兩者並見），
> 通行本作「圮地」，義為毀壞難行之地。本檔採「圮地」。

**九句處置的共同結構**：每一句都是「**在這種處境下，什麼是最貴的動作**」。
散地決戰貴、爭地強攻貴、圍地硬拚貴、死地猶豫貴。**九地不是教你怎麼贏，
是教你在每種處境下避開最貴的那個選項。**

## 三、三條可遷移的原理

1. **處境由關係決定，不由地圖決定**。同一個地點，我方視角是散地，對方視角是重地。
   **分析前先確認你站在誰的位置上**——這與 `06` 步驟①「界定棋盤」是同一件事。
2. **最好的處置常常是不動作**。九句裡有四句是「不要做什麼」（無戰、無止、無攻、無絕）。
   **辨識出「此處不宜行動」與辨識出「此處該進攻」同等重要。**
3. **處境會轉換**。爭地拿下之後可能變成重地（補給拉長），輕地推進之後變成重地。
   **要預判自己下一步會落進哪一種地**，而不是只判斷現在在哪一種。

## 四、現代轉譯（可用於不動產、專案、商業競爭）

> **這是類比，不是等式。** 用途是**提示該注意什麼**，不是分類後直接照表行動。
> 每一格的「處置」都要回到具體條件重新驗證。

| 地型 | 現代對應的處境 | 提示的動作 |
|---|---|---|
| 散地 | 自有土地、本業主場、無時間壓力的案子 | 不必急著動；**主場容易鬆懈，最大風險是內部拖延**而非外部競爭 |
| 輕地 | 剛跨出熟悉範圍的小規模試水（新區域、新產品線） | 設停損、不重壓；**要嘛快速確立位置，要嘛快速退出**，最忌卡在中間 |
| 爭地 | 人人都看好的熱點（捷運站周邊、風口產業） | **價格已反映預期，硬搶最貴**；找側翼、找時間差，或不碰 |
| 交地 | 多方都能進入、無進入障礙的市場 | 重點是**不被斷聯**：維持通路、供應商、資金線的多元 |
| 衢地 | 多方交界、誰先結盟誰得勢（公辦都更、跨單位標案） | **先做關係與聯盟，不要先做方案**；價值在協調位置 |
| 重地 | 深入陌生市場的大投入（跨區大面積、海外） | **必須就地建立補給**：本地團隊、本地供應鏈、長資金彈性 |
| 圮地 | 條件惡劣、難以施展的案子（法規混沌、地質困難） | **通過就好，不要駐紮**；不要在此建立長期部位 |
| 圍地 | 進場窄、退場更窄（巷弄狹小、產權破碎、被古蹟或既有結構夾擊） | 硬幹無效，**靠設計與談判找出路**；先確認退場方案再進場 |
| 死地 | 已無退路（限期拆除、資金斷點、法拍最後一拍） | **猶豫比決策錯誤更貴**；設定決策時限，速戰 |

## 五、與五鏡的接法

九地掛在**軍事鏡**之下，作為「處境判定」的工具：

```
五鏡：這塊地值多少、由哪一層決定       ← 靜態評估
  └ 九地：我此刻在這塊地上是什麼處境    ← 動態處置
```

**使用順序**：先跑 `06` 七步 SOP 得到地緣體檢表（值多少），
再判九地（現在該怎麼動）。**跳過前者直接判九地，會變成用兵法術語包裝直覺。**

## 五-A、一則實例：兩種地重疊時怎麼判（2026-09 實跑）

**情境**：老街區的一戶所有權人，考慮發起危老重建；制度端有明確申請期限，
且修法方向同時包含「取消期限」與「限縮適用」。

| 面向 | 判定 | 依據 |
|---|---|---|
| 作為發起人 | **圍地** | 入口窄（危老須全體所有權人同意）、退路迂（啟動後卡在某一戶，時間與費用沉沒） |
| 在期限壓力下 | **死地** | 制度時窗有期限，疾戰則存 |

**衝突判定**：依第六節第 2 項「**以代價最高的那一種為準**」——
**圍地的「謀」壓過死地的「戰」**。

**實務結論**：不因期限壓力而先花錢做評估、找廠商；**先確認同意度**。
**進不去就談不上快**；順序錯了，錢會沉在最前面。

> **這一則的價值不在結論，在示範怎麼處理衝突。**
> 兩種地重疊是常態不是例外，而「以代價最高者為準」這條規則，
> 幾乎總是把答案從「快動」推向「先確認能不能動」。

## 六、三個誤用警告

1. **不要用九地做分類遊戲**。把每個案子貼上一個地型標籤，然後宣稱分析完成——
   標籤不是分析。**要能說出「因為 X 條件，所以此處硬攻最貴」才算用對。**
2. **不要忽略「同時屬於多種地」**。實務上一個案子常同時是爭地與圍地
   （人人想要，但進退都窄）。**兩種處置衝突時，以代價最高的那一種為準**——
   圍地的「謀」壓過爭地的「無攻」，因為進不去就談不上爭。
3. **不要把敵我語言帶進沒有對手的情境**。很多案子的困難來自法規、地質與資金，
   不是來自對手。**沒有對手的地方套用九地，會虛構出一個不存在的敵人**，
   並因此做出過度防禦的決策。
