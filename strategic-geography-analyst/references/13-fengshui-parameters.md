# 13 風水作為分析參數：三類編碼法

> **本檔的立場先講清楚，以免被誤讀兩次。**
>
> - 本 skill **不主張**風水具有超出物理與心理機制之外的因果效力。
> - 本 skill **也不主張**風水可以被忽略——**它是台灣不動產市場的真實變量**：
>   影響買方接受度、成交價、去化速度與客訴率。**忽略它會算錯錢。**
>
> 這兩句不衝突。**一個因素不需要「為真」才能「有影響」**——
> 只要夠多人相信它，它就會出現在價格與銷售速度裡。本檔要做的，
> 是把它拆解成**可驗證、可估價、可決策**的參數，而不是照單全收或整包丟掉。

---

## 一、三類編碼（本檔的核心方法）

風水的內容不是同一種東西，混在一起談就會變成信或不信的爭論。**先分三類：**

| 類 | 內容性質 | 能不能還原成物理變量 | 進哪一鏡 | 用什麼驗證 |
|---|---|---|---|---|
| **A 類：形勢可還原** | 巒頭／形勢派的觀察（背山面水、藏風聚氣、明堂、路沖、反弓、低窪） | ✅ 可還原成地形、風、水、日照、噪音、安全 | 山川鏡＋天時流場 | **物理判準**（實測、模擬、法規） |
| **B 類：不可還原但可市場觀測** | 理氣派方位吉凶、樓層與門牌數字、格局忌諱（穿堂、開門見廁、正對電梯）、鄰避設施忌諱 | ❌ 無物理對應 | **經濟鏡（需求端偏好）** | **市場資料**（成交價差、去化天數、拒看率） |
| **C 類：不可還原也不可觀測** | 擇日、命卦配屋、個人化改運 | ❌ | 政治鏡（利害關係人偏好） | 不驗證；**當成關係人的既定條件處理** |

> **這個三分法是本檔全部價值的所在。** 分完之後，
> A 類回到工程與設計去驗證，B 類回到財務去估價，C 類回到溝通去協調。
> **沒有任何一類需要先回答「風水到底準不準」。**

---

## 二、A 類：形勢派的物理還原表

形勢派（巒頭）的判斷對象，與現代基地分析的觀察對象**高度重疊**——
兩者都在看地形、風、水、日照與動線。**把它讀成前科學時代的經驗地理學編碼，
比讀成玄學更有用。**

| 風水說法 | 可還原的物理變量 | 驗證方法 | 判準 |
|---|---|---|---|
| **背山面水** | 背側屏障擋冬季風、前方開闊採光與視野、近水源 | 風向資料＋日照分析＋高程 | 若基地背側無屏障而迎冬季季風，物理上確實不利（`02` 流場） |
| **藏風聚氣** | 避免強風通道與風切；微氣候穩定 | 風速實測、CFD、街谷效應 | 強風廊道會降低戶外舒適度與外牆耐候 |
| **明堂開闊** | 前方無壓迫、採光通風與視野良好 | 棟距、遮蔽角、日照時數 | 與日照權、視覺景觀是同一件事 |
| **忌路沖**（道路直沖） | 車輛動線直指、噪音與夜間車燈、事故風險 | 交通量、車速、噪音實測 | **物理上確實成立**：直沖處的噪音與安全風險較高 |
| **忌反弓**（道路外側彎） | 車輛離心方向、視距不良、噪音 | 曲率半徑、事故紀錄 | 部分成立：外側彎的失控車輛風險確實較高 |
| **忌壁刀／天斬煞**（鄰棟夾峙） | 建物間隙的風切加速、壓迫感 | 風速模擬、遮蔽角 | 風切效應為真；壓迫感屬心理，見 B 類 |
| **忌低窪／背水** | 排水不良、淹水潛勢 | 高程、淹水潛勢圖、排水系統 | **完全成立**，且是 `09` 模組 4 的正規項目 |
| **忌無尾巷** | 消防與逃生動線單一、通風不良 | 巷寬、消防車進入、通風 | **完全成立**，且直接關聯法規與 `11` 的「圍地」處境 |
| **忌鄰高壓電／變電設施** | 電磁疑慮、噪音、視覺 | 距離、設施類型 | 部分成立（噪音與視覺確定，健康效應另有爭議）；**且它是不可移動的既定物**（`09` 要素 6） |

**A 類的使用紀律（三條）**：

1. **以物理判準為準，風水說法只當助記**。兩者衝突時，**一律以實測與模擬為準**。
2. **不可反推**。「因為風水說好，所以物理上一定好」是錯的方向；
   只能「物理上確實不利，而風水恰好也標示了它」。
3. **不可用於安全判斷**。結構、地質、消防、擋土的判斷，**只能來自工程計算**。
   風水對此沒有任何發言權，這條沒有例外。

> **一個實際的觀察**：前面語料裡的手繪基地圖標了三處「電箱」。
> 這同時是：風水的忌諱、物理上的噪音與視覺問題、以及**遷移權不在自己手上的既定物**。
> **三個系統同時指向同一個點，代表那真的是個問題。** 這就是 A 類的正確用法。

## 三、B 類：需求端偏好參數（進經濟鏡）

B 類沒有物理對應，但**有市場對應**。它的正確位置是需求端：
**不是「這房子不好」，而是「這房子的可售客群變小、去化變慢、議價空間變大」。**

### 三個可操作的參數

| 參數 | 定義 | 怎麼估 |
|---|---|---|
| **敏感度 S** | 目標客層對風水的在意程度 | 依產品定位與客層判斷（見下表），**不是全市場一個值** |
| **價差影響 ΔP** | 相同條件下，該忌諱造成的成交價折讓 | 用同社區／同路段的可比交易估；**沒有可比資料就標「不可估」，不要猜** |
| **去化影響 ΔT** | 銷售天數的延長 | 建案銷售紀錄；**多數情況下 ΔT 比 ΔP 更敏感**——買方常不砍價，只是不買 |

### 敏感度分級（起始判斷，須以個案資料校準）

| 客層／產品 | 敏感度 | 理由 |
|---|---|---|
| 自住型、家庭客、中高齡買方 | **高** | 長期居住、家族意見多、購屋為人生大事 |
| 首購年輕客層 | 中 | 在意但價格優先，可用折讓換取接受 |
| 投資與收租型 | 中低 | 看報酬率；但**要考慮下一手買方的敏感度**（轉手風險） |
| 商業與辦公 | 中 | 老闆個人偏好差異極大；**決策者一個人就能否決** |
| 工業與物流 | 低 | 以機能為主 |

> **最重要的一條**：敏感度是**對下一手買方**的敏感度，不是對現在這個決策者的。
> 投資客自己不信，但他要賣給信的人——**風險會傳遞。**

### 常見 B 類項目（台灣市場）

| 項目 | 典型影響 | 可否設計解決 |
|---|---|---|
| 樓層與門牌數字（4、14 等） | 價差常見、去化變慢 | ❌ 不可改；**只能在定價階段吸收** |
| 穿堂煞（前後門或窗直通） | 格局被挑剔 | ✅ 玄關、屏風、隔屏可解 |
| 開門見廁／見灶 | 格局被挑剔 | ✅ 平面調整即可解 |
| 正對電梯／樓梯 | 中等 | ⚠️ 部分可用玄關緩解 |
| 緊鄰宮廟、殯葬、醫院 | **影響顯著且不可逆** | ❌ 不可解，**應在購地評估階段就計入** |
| 高壓電、變電設施 | 顯著 | ❌ 多不可解（見 A 類） |

**分類的實務意義**：**可設計解決的項目，成本落在設計階段（便宜）；
不可解的項目，成本落在土地價格與定價策略（貴）。**
所以 B 類必須在**購地評估**時就查，不能等到規劃階段。

## 四、C 類：關係人偏好（進政治鏡）

擇日、命卦、個人化改運等，**不驗證、不評價，當成利害關係人的既定條件處理**——
與「業主偏好某種立面材質」在管理上是同一類事情。

**三條處理原則**：

1. **提早問，不要等到衝突才發現**。開工、上樑、交屋的擇日需求，
   **直接影響工期與里程碑**；納入 `09` 階段①的利害關係人盤點。
2. **量化它的代價**。「擇日只能選這三天」等於工期限制，
   **要換算成天數與成本，並讓決策者知道這個數字**。
3. **不評論其真偽**。專業立場是把它當成需求來管理，不是說服對方放棄。
   **但如果它與工安或結構衝突，工程判斷優先，這條不能讓。**

## 五、接進五鏡的完整路徑

```
風水輸入
   ├─ A 類 → 還原成物理變量 → 山川鏡／天時流場 → 用實測與模擬驗證
   │                                            └→ 與物理判準衝突時，物理優先
   ├─ B 類 → 需求端偏好 → 經濟鏡 → 用市場資料估 ΔP、ΔT
   │                              └→ 進入土地評估與定價，不進工程判斷
   └─ C 類 → 關係人條件 → 政治鏡 → 換算成工期與成本，納入利害關係人管理
```

**在 `09` 六階段裡的位置**：

| 階段 | 風水相關動作 |
|---|---|
| ① 確認目的與因素 | 判定客層敏感度 S；盤點關係人的 C 類需求 |
| ⑤ 調查作業 | A 類隨基地調查一併查（本來就要查）；B 類查鄰避設施與周邊環境 |
| ⑥ 成果分析運用 | B 類進「土地價值及利用效益」與「開發限制」；不可解項目列為門檻 |

---

## 六、五條誤用警告

1. **不得用於安全與工程判斷**。結構、地質、消防、擋土、開挖——
   **只認工程計算**。這條沒有例外，也不因業主要求而改變。
2. **不得聲稱因果**。正確說法是「此格局在目標客層中接受度較低，
   反映在去化天數上」，不是「此格局會導致某種後果」。
3. **不得用來拒絕人或評價人**。風水偏好是市場事實，
   **不是評判買方或業主理性程度的依據**；分析者的工作是估算影響，不是說服。
4. **不得在沒有可比資料時給精確折讓數字**。「大約折 3%～5%」若無可比交易支撐，
   就是 `09` 第八節第 7 項的「用小數點假裝有精度」。**沒資料就說沒資料。**
5. **不得讓 B 類凌駕 A 類的物理結論**。若某方位在風水上被視為吉，
   但物理上是西曬最嚴重、噪音最大的一面，**設計仍應處理物理問題**；
   兩者的協調屬設計課題，不是取捨題。

## 七、與 `12` 的關係（一個必要的對照）

`12` 指出「基地」一詞已預設人類目的。風水在這件事上是個有趣的反例：
**它是一套把人與環境關係編碼進日常決策的傳統系統**——
背山面水、藏風聚氣關心的是人在環境中的舒適與安全，
與 `12` 的生態視角有部分共通（都反對把土地當純粹的可開發面積）。

**但兩者不可互相取代**：`12` 的不可逆性與生態承載力，
風水系統沒有處理；風水的市場影響力，`12` 也不處理。**各自進各自的位置。**
