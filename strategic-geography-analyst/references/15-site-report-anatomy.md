# 15 基地分析報告的解剖：一份真實成果文件的章節架構

> **語料來源**：使用者提供之掃描 PDF（2026-09-05 匯入），為**張志成建築師事務所**
> 某新建工程規劃報告的第肆章〈基地環境背景分析〉（頁碼 -15- 至 -26-），
> 標的為國立臺灣大學校總區某新建大樓（原址為三棟合院式舊館）。
>
> **性質**：第三方專業成果文件 → 依 `10` 的增補規範節，**只收章節架構、寫法與方法，
> 不轉錄個案的地號、尺寸、法規數值與結論**。
>
> **這一檔補的是「成果長什麼樣」**：`09` 給程序、`14` 給方法、`12` 給界限——
> 但一份基地分析報告實際上該怎麼分章、每章回答什麼，一直沒有範本。

## 一、七章架構：一個由外而內的漏斗

| 章 | 名稱 | 回答什麼 | 尺度 |
|---|---|---|---|
| 一 | **區位環境背景分析** | 這塊地在城市裡是什麼角色？ | 行政區／都會 |
| 二 | **自然環境背景分析** | 地形與氣候給了什麼條件？ | 基地與周邊 |
| 三 | **相關公共設施建設計畫** | 周邊有什麼、以及**將要有什麼**？ | 步行圈至區域 |
| 四 | **軸線與機能分析** | 這塊地在既有空間結構中的位置？ | 街廓／園區 |
| 五 | **基地區位分析與周圍土地使用現況** | 基地本身與緊鄰四周的實況？ | 基地 |
| 六 | **基地潛力與限制條件分析** | 所以能做什麼、不能做什麼？ | 基地 |
| 七 | **基地植栽調查** | 哪些既有物必須保留？ | 基地 |

**三個結構特徵值得沿用**：

1. **由外而內，尺度逐章收斂**——先講城市角色，最後才講基地本身。
   讀者是先理解脈絡再看細節，不是反過來。
2. **第六章是全章的收束**：前五章都是事實，**第六章是唯一給判斷的一章**。
   這與 `09` 「調查是輸入、判斷才是輸出」完全一致。
3. **第七章單獨處理植栽**——不併入自然環境，因為它是**逐株定位、影響配置與施工的
   既有物**，性質接近測量而非背景描述。

> **對照 `09` 六階段**：本架構是六階段中「⑥成果分析運用」的**文件化形式**。
> 六階段講怎麼做，本檔講做完之後怎麼寫。

## 二、第三種時間維度：周邊建設的排程

第三章「相關公共設施建設計畫」分兩段寫：

- **（一）現有設施**：學校、圖書館、醫院、市場、公園等，分類列舉。
- **（二）重大建設計畫**：**依時態分成三類**——已完工、正在進行、將要進行。

**這一段補上模型缺的第三種時間來源。** 至此時間窗有三個出處：

| 來源 | 內容 | 特性 | 在哪一鏡 |
|---|---|---|---|
| **自然** | 季節、汛枯、日夜 | 週期循環、可預測 | 天時流場（`02`） |
| **制度** | 法規期限、獎勵落日、修法方向 | 單向、會被人為改寫 | 政治鏡（`04` 第五節） |
| **周邊建設** | 已完工／進行中／將進行的鄰近工程 | **實體環境本身在變**，且有排程 | 物流鏡＋政治鏡 |

**為什麼第三種重要**：基地分析寫的是「現況」，但案子完工時面對的是**幾年後的環境**。
鄰地正在蓋的東西，會改變視野、車流、日照、人流與噪音。
**只分析現況，等於用過期的環境條件做設計。**

**操作方式**：把周邊工程列成清單，各標**位置、性質、預計完工時間**，
並逐一問：**它完工後會改變本案的哪一項分析結論？**

## 三、軸線與端點：都市／園區尺度的空間結構

第四章的軸線分析是本語料最可遷移的一段。它的寫法是：

```
軸線 = 起點 → 沿線的意義載體 → 端點
```

- **縱向（主）軸線**：由某入口起，以某地標為端點；沿線分布具歷史人文意義的建築。
- **橫向（次）軸線**：與主軸垂直，是日常活動動線；同樣標明兩端的端點。
- **新建築的義務**：報告明確指出，新館改建後**應能由主軸直視某端點**——
  **新建物必須處理它與既有軸線的關係，這是設計條件，不是選項。**

**三條可遷移的判準**：

1. **軸線要有端點才成立**。沒有端點的長條空地只是通道，不是軸線；
   **端點是使軸線被感知的東西**。
2. **軸線分主次**：主軸承載象徵與識別，次軸承載日常動線。
   **兩者的設計責任不同**——主軸要求呼應，次軸要求順暢。
3. **既有軸線是不可協商的**。擋斷或錯位一條既存軸線，代價是整體結構被破壞，
   且反對聲音來自所有使用者，不只鄰地。

> **接回 `14` 與 `02`**：軸線就是 `14` 的「穿越基地的視野」在園區尺度的版本，
> 也是 `02` 山川鏡的「通道」。三者是同一個概念在不同尺度的名字。

## 四、潛力與限制條件：成對書寫

第六章是全報告唯一給判斷的一章，寫法是**兩欄成對**：

| 潛力條件（能做什麼） | 限制條件（不能做什麼／要付什麼代價） |
|---|---|
| 現況：基地形狀是否方正完整 | 現況：哪些既有建物必須拆除、哪些既有設施必須一併整體考量 |
| 區位：門戶意象、地標性 | 上位計畫：須配合整體規劃準則、量體高度須呼應鄰近低矮歷史建物 |
| 法定條件：可用的建蔽容積 | 植栽：既有樹木的保存與維護 |
| | **對周圍使用的影響：施工噪音、施工安全、交通停車如何避免干擾既有活動** |
| | 地下管線：設計前須先了解管線現況並配合上位管線計畫 |

**四個值得記下的寫法**：

1. **潛力與限制用同一組欄位對寫**（現況、區位、法規…），**同一件事的兩面同時出現**。
   例如「位於入口」既是門戶意象的潛力，也是施工干擾的限制。
2. **限制條件比潛力條件多，是正常的**。潛力多半三兩項就講完，
   限制才是決定成敗的地方。**限制欄位太短，通常代表沒查完。**
3. **「對周圍土地使用現況之影響」被列為限制條件之一**——
   也就是**施工期的噪音、安全、交通停車被寫進基地分析報告**。
   這正面驗證了 `09` 第六節第 9 項：**施工期與完工期是兩套系統，都要分析。**
   本案把它提到報告層級，不是留給施工計畫。
4. **地下管線列為獨立一項**，且要求「設計前先了解現況並配合上位管線計畫」——
   呼應 `09` 要素 6：遷移權不在自己手上的既定物，必須前置處理。

## 五、圖照與視點的編號慣例

本報告使用一套簡單但嚴謹的編號，值得沿用：

| 類型 | 編號方式 | 作用 |
|---|---|---|
| 圖 | 圖4-1、圖4-2… | 章號-序號；區位圖、機能分析圖、基地現況圖 |
| 照片 | 照片4-6～4-17 | 同上，連號 |
| **視點** | **V1、V2、V3、V4** | **標在基地現況圖上，與照片一一對應** |

**視點編號是關鍵**：把 V1～V4 標在平面圖上，讀者能立刻知道**每張照片是站在哪裡、
朝哪個方向拍的**。沒有視點編號的現勘照片，讀者無法定位，價值大減。

> **接回 `14` 視野三分法**：視點編號其實就是「對基地的視野」的取樣點。
> 拍照時就該問：**這個視點屬於對外、對內，還是穿越？**

## 六、一個校勘發現：氣候資料的統計期間有兩個版本

本報告第二章引用的氣候統計表，**與 `10` C 節收錄的那份逐格數值完全相同**
（含「表4-1」與「表八」並用的表號不一致），但——

| 出處 | 標示的統計期間 |
|---|---|
| `10` C 節（使用者提供之獨立 .docx／.pdf） | **1970～2000** |
| 本報告 | **1971～2000** |

**兩項推論**：

1. **`10` C 節那份氣候資料，極可能是從這類專業報告節錄出來的**，
   而非獨立的課程教材——文字一字不差，連表號不一致的錯誤都相同。
   這部分回答了 `10` E-3 提出的分類疑問。
2. **統計期間的差異需查證**。中央氣象局的三十年平均值通常以
   1971～2000 或 1991～2020 等整三十年為期；**1970～2000 是 31 年，較不合常規**，
   但本 skill **不臆測何者為正**，兩個版本並記，
   引用時一律連同出處與期間一起講（見 `10` C 節使用限制）。

> **這一則的方法意義**：**同一份數據在不同文件裡的細微差異，是判斷文件親緣關係的證據。**
> 校勘不只是挑錯字，也是追來源。

## 七、把這份架構接進既有流程

```
09 六階段（怎麼做）→ 14 雙列矩陣（怎麼轉成設計）→ 15 七章架構（怎麼寫成報告）
                                      ↑
                            12 五題（寫完之後檢查）
```

**實用建議**：接到新案要寫基地分析時，**用第一節的七章當目錄先搭出來**，
再用 `09` 的三大類清單去填每一章的內容，最後用 `14` 的雙列矩陣把
第六章的限制條件轉成設計回應。**架構先行，資料才不會變成一盤散沙。**

**另一種成果形式見 `16`**（圖板）：報告可查核、圖板可說服，
**兩者用途不同不可互相取代**，對照表見 `16` 第八節。
`16` 也接手了本檔第六章之後的三段——**課題收斂、設計準則、行動分期**。
