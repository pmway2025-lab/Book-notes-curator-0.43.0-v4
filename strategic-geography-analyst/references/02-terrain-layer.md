# 02 山川鏡：把地形讀成五種要素

> 五鏡的最底層。這一層不談誰打誰，只回答：**這塊空間的骨架長什麼樣、
> 什麼力量週期性地掃過它。**

## 五要素分類法（讀圖第一步）

任何一塊地形，先拆成四類**空間要素**（地利）＋一類**流場要素**（天時）。
前四類窮盡了地形對移動的影響，第五類補上地形不能表達的方向性能量。

| 要素 | 定義 | 地貌形態 | 戰略含意 |
|---|---|---|---|
| **障壁** | 阻礙大隊移動與補給的地形 | 山脈、大河、沙漠、沼澤、海 | 降低受攻面，**也降低自己的出擊面** |
| **通道** | 障壁之間或之上可通行的線 | 河谷、走廊、平原缺口、航道 | 力量的血管；**流量集中處必生節點** |
| **門戶** | 通道上寬度最窄、無法繞行的一段 | 隘口、渡口、峽道、海峽 | 少量兵力可制大部隊；**要地的真身** |
| **腹地** | 障壁之內可耕可居的平原盆地 | 盆地、沖積平原、河谷平原 | 養力的地方；**決定能撐多久** |
| **流場** | 週期性掃過空間的方向性能量 | 季風、日照、汛期、洋流、暴雨、噪音 | 不阻擋移動，但**決定何時能動、朝哪面開口** |

**核心判準**：一塊地是不是「形勝」，等於問**障壁是否閉合、門戶是否可控、腹地是否夠養**。
三者缺一，就只是「地勢險」而不是「形勝」。險而無腹地，是絕地不是要地。

**前四類與第五類的分工**（這是本模型的地利／天時之分）：

```
地利（空間常數）：障壁／通道／門戶／腹地  ← 決定「能不能走、走多貴」
天時（時間變數）：流場                    ← 決定「什麼時候走、朝哪一面」
```

**流場為什麼要獨立成一類**：它有方向、有季節，卻不承載物質、也不阻擋移動，
四要素沒有位置放它。古代的對應物一點都不冷僻——風向與火攻、汛期與行軍季節、
日照方位與列陣、瘴癘與駐屯選址，都是流場而不是地形。**忽略流場的分析，
會把「這條路走不走得通」答對，卻把「什麼時候走」整個漏掉。**
（基地／建築尺度的流場讀法見 `09`：季風、日照軌跡、雨季、噪音源。）

## 形勝五問（逐項回答，不要跳）

1. **屏障閉合嗎？** 障壁圍成幾分之幾？缺口有幾個？——缺口數決定要防幾處。
2. **門戶可控嗎？** 每個缺口最窄處在哪？能不能繞？繞路要多付幾天？
3. **腹地養得起嗎？** 內部可耕面積、水源、人口；**能不能在被圍時自給**。
4. **出得去嗎？** 守得住而出不去＝地緣牢籠。攻勢地形與守勢地形要分開評分。
5. **上下游關係？** 水系上下游是不對稱的：**上游天然壓迫下游**，順流可下、逆流難上。

> 五問全高＝四角級的形勝之地；②⑤高而③低＝門戶／樞紐；③高而①②低＝富庶的四戰之地
> （最危險的組合：養得起，守不住，人人都想要）。

## 流場三問（第五要素的專屬提問）

形勝五問只問空間。流場另外問三題，**每一題都必須標出「方向」與「季節」**：

1. **哪些流場掃過這裡？** 主風向（分冬夏）、日照弧線、汛期與枯水期、
   雨季、以及現代尺度的噪音與污染來源。
   **注意尺度有三層**：季節（冬夏反向）、**日夜**（海風／陸風日夜反轉）、
   長週期（汛枯、氣候趨勢）。只看季節會漏掉日夜反轉。
2. **方向會不會反轉？** 冬夏季風常常相反、河流有汛枯之別。
   **只按單一季節做的配置，會在另一個季節付代價**——這是流場最常被漏掉的一點。
3. **它改變的是什麼？** 分清三種效果：
   - **時間窗**（可行動的季節：汛期不能渡、颱風季不能吊裝）
   - **朝向**（哪一面該開口、哪一面該封閉）
   - **成本**（順風順流省，逆風逆流貴——與水系上下游同理）

> **判讀**：流場不改變「能不能」，只改變「何時、朝哪、多貴」。
> 但戰略上多數失敗不是敗在能不能，是敗在時機與朝向。
>
> **時間窗有兩個來源**：自然的（本節，週期循環、可預測）與**制度的**
> （法規期限、獎勵落日、修法方向——見 `04` 第五節「制度時窗」）。
> **後者是單向的，而且會被人為改寫**，錯過可能沒有下一個週期。

**有統計資料時，把三問做成量化剖面**：氣候常值（逐月雨量、雨日、氣溫、
溼度、日照、風向風速）可以把「雨季不好走」變成「這幾個月有幾天不能作業」。
方法見 `09` 第三-A 節。**但年平均會抹掉季節落差，一律逐月看。**

## 水系的三重身分

中國式軍事地理裡，河流從來不是單一角色，**同一條河同時是**：

| 身分 | 作用 | 判斷 |
|---|---|---|
| 障壁 | 橫向阻隔 | 看**渡口數量**：渡口少的河才是防線 |
| 通道 | 縱向運輸 | 看**通航條件與流向**：順流是加速器，逆流是稅 |
| 供養 | 灌溉與人口 | 看**沖積平原寬度**：河谷寬則養人，峽谷則只過兵 |

**因此**：一條河對某方是防線、對另一方是高速公路，是常態而不是矛盾。
分析時務必分別站在雙方視角各評一次。

## 地形的三種欺騙性（最容易犯錯的地方）

**① 險要的錯覺**——「地勢險」不等於「守得住」。真正決定防守的是
**能不能被繞過**，以及**繞路的代價是否小於強攻的代價**。無法繞的窄口比高的山重要。

**② 完整的錯覺**——地圖上閉合的屏障，實際上常有季節性缺口：冬季封凍的河、
枯水期的淺灘、可行的獸道與棧道。**防線的強度等於它最弱一段的強度**，不是平均值。

**③ 靜態的錯覺**——地形是常數，但**權重不是**。技術（渡河、築路、鐵路、空運）、
制度（動員能力、財政）與對手的目標，都會重寫同一個地形的分數。
**同一個門戶，在不同時代可能從一級要地掉成觀光景點。**

## 輸出格式（骨架速記）

分析任何區域時，用這個格式先寫五行，再往上層走：

```
障壁：<有哪些，圍住幾面，缺口幾個>
通道：<主通道 2-3 條，各自連接誰到誰>
門戶：<每條通道的最窄點，是否可繞>
腹地：<可養人的核心區在哪，規模等級>
水系：<主要水系流向，誰在上游>
流場：<主風向（冬／夏）、日照或汛枯、可行動的時間窗>
```
