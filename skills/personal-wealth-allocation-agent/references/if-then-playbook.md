# IF...THEN 應變清單（理財長 AGENT）

用法：使用者丟出情境時，先在此表定位，再依 SKILL.md 的輸出格式回答。
每一條的 THEN 都是**動作**，不是安慰。

---

## A. 資料不足與起手式

1. IF 直接問「該買什麼」且無現況資料 → THEN 先問四題（收入／支出／現金／負債），
   給「暫定框架」而非商品名稱。
2. IF 使用者拒絕提供數字 → THEN 改用比例回答（幾成股、幾成債、幾個月緊急金），
   並說明沒有數字時建議精度有限。
3. IF 儲蓄率 < 10% → THEN 議題不是投資，是現金流。做支出結構分析與收入路徑。
4. IF 儲蓄率 > 40% 且無明確目標 → THEN 檢查是否過度壓抑當期生活品質，
   把「生活品質預算」也列成一個目標。

## B. 安全順序類

5. IF 緊急金 < 6 個月（穩定薪）或 < 9 個月（不穩定收入） → THEN 先補現金，
   投資延後或降額。
6. IF 有利率 > 6% 的負債 → THEN 優先清償；還債是無風險、確定的報酬。
7. IF 有卡循／現金卡 → THEN 最高優先，全部可動用資金先清這一項。
8. IF 沒有實支實付或失能保障、卻已在做高風險投資 → THEN 先補保障缺口。
9. IF 年繳保費 > 年收入 15% → THEN 做保單體檢（轉 `insurance-coverage-checkup`），
   多半是儲蓄型／投資型佔用了保障預算。

## C. 期限與目標類

10. IF 這筆錢 5 年內要用 → THEN 不進股市，只談定存／短債／貨幣型。
11. IF 目標所需報酬率 > 8% → THEN 不是加碼風險，而是重談目標金額或延長年限，
    或增加投入金額。三選一，攤開來讓使用者選。
12. IF 使用者要在 1 年內湊到頭期款 → THEN 全部現金化，不做任何波動性配置。
13. IF 有子女教育金需求 → THEN 依「用錢年份」分層，越接近使用年份越保守。

## D. 配置與集中度

14. IF 單一標的 > 淨值 20% → THEN 標示集中度風險，給 12–24 個月的分批減碼路徑。
15. IF 自家公司股票＋員工認股 > 淨值 10% → THEN 提醒「薪水與資產同源」，
    這是雙重曝險，優先降低。
16. IF 持有 5 檔以上高度重疊的 ETF → THEN 做成分重疊檢查，合併成核心部位。
17. IF 全部資產在台股 → THEN 說明單一國家／單一產業集中度，提出全球分散選項。
18. IF 全部資產在美元資產、但未來支出是台幣 → THEN 提出匯率錯配風險與部分回補。
19. IF 想配置加密資產 → THEN 上限 5%，視同可能歸零，且不可動用緊急金或借貸。

## E. 市場波動

20. IF 市場大跌、使用者想全部出場 → THEN 回到計畫文件：買進理由是否失效？
    若只是價格下跌，執行原再平衡規則；若真的睡不著，降低股票目標權重到可承受
    水準並寫下來，而不是清空。
21. IF 市場大漲、使用者想加碼追高 → THEN 用再平衡規則檢查是否已超配；
    超配就是減碼訊號，不是加碼訊號。
22. IF 使用者問「現在是不是進場時機」 → THEN 不預測。改談「一次投入 vs 分批」
    的行為權衡，並設定固定投入排程。
23. IF 帳面虧損想「攤平」 → THEN 反問：若今天手上是現金，還會買這檔嗎？
    是→那是再平衡；否→那是沉沒成本。
24. IF 出現「這次不一樣」的敘事 → THEN 問這個敘事是否已反映在價格上，
    並檢查它會不會讓計畫的最壞情境變糟。

## F. 生涯與收入變動

25. IF 換工作／收入中斷 → THEN 暫停新增投入，緊急金拉到 12 個月，
    保單改繳費最小化但不斷保。
26. IF 收入為專案型（工程、接案、業務） → THEN 用近 12 個月**平均**收入設定投入，
    高峰月的超額收入先補緊急金與年度不定期支出準備金。
27. IF 加薪或領到大筆獎金 → THEN 先按既有比例分配（緊急金→負債→投資），
    並把「生活成本膨脹」控制在加薪額的一半以內。
28. IF 準備創業／自行接案 → THEN 生活費 12–18 個月獨立備妥，
    創業資金與投資帳戶完全分離，不可互相支援。
29. IF 結婚／生育 → THEN 重做保障缺口（壽險額度、扶養年數）與目標分層。
30. IF 準備購屋 → THEN 頭期款移出成長層；試算「買房後」的緊急金與月付比。

## G. 紅旗與停損

31. IF 出現「保證獲利／穩賺／內線／代操／出金要先繳稅」 → THEN 停止理財討論，
    判定為高度詐騙訊號，轉 `scam-bayes-detection`，提醒 165。
32. IF 要用信貸、房屋增貸、融資槓桿投資 → THEN 先算最壞情境（−40% 且被追繳、
    同時失業 6 個月）。過不了就不做；過得了也要把槓桿倍數與追繳線寫下來。
33. IF 使用者情緒溫度高（急、怕錯過、憤怒） → THEN 強制 24 小時冷靜期，
    先寫決策紀錄表再執行。
