# 財務體檢問卷、資料範本與年度檢視 SOP

---

## 1. 財務體檢問卷（分批問，不要一次丟完）

**第一批（沒有這四題無法給任何配置建議）**
1. 月稅後收入大約多少？其中固定薪與變動（獎金／專案）各佔多少？
2. 月支出大約多少？年度不定期支出（保費、稅、旅遊、孝親）約多少？
3. 目前可動用現金（活存＋定存）多少？
4. 有沒有負債？餘額、利率、月付各多少？

**第二批（配置設計用）**
5. 現有投資部位有哪些？各多少金額？
6. 保險有哪些？年繳保費多少？有沒有實支實付與失能保障？
7. 未來 5 年有哪些確定要花的大錢（購屋、結婚、進修、換車、生育）？
8. 退休大概想在幾歲、每月想有多少生活費（以今天的物價算）？

**第三批（風險屬性用）**
9. 這筆錢帳面 −30%、而且持續兩年，你會怎麼做？（加碼／不動／減碼／出場）
10. 過去有沒有投資經驗？最痛的一次是什麼？後來怎麼處理？
11. 你的收入受景氣影響大嗎？失業後多久能找到同等收入的工作？
12. 有沒有人在經濟上依賴你？

## 2. `profile.json` 範本（給 `portfolio.py checkup` 用）

```json
{
  "age": 32,
  "monthly_income": 75000,
  "monthly_expense": 45000,
  "annual_lumpy_expense": 120000,
  "income_stability": "variable",
  "cash": 600000,
  "investments": 800000,
  "other_assets": 0,
  "debts": [
    {"name": "信貸", "balance": 300000, "rate": 0.068, "monthly_payment": 9000},
    {"name": "房貸", "balance": 0, "rate": 0.021, "monthly_payment": 0}
  ],
  "insurance_annual_premium": 60000,
  "risk_profile": "moderate",
  "dependents": 0
}
```

`income_stability`：`stable`（固定薪）／`variable`（獎金或專案佔比高）／
`irregular`（接案、業務、無固定薪）。
`risk_profile`：`conservative` / `moderate` / `aggressive`。

## 3. `holdings.json` 範本（給 `portfolio.py rebalance` 用）

```json
{
  "holdings": {
    "台股市值型ETF": 450000,
    "海外股票ETF": 520000,
    "投等債ETF": 180000,
    "現金與定存": 350000
  },
  "targets": {
    "台股市值型ETF": 0.25,
    "海外股票ETF": 0.40,
```

`targets` 權重總和需為 1（工具會檢查，誤差 > 0.5% 會報錯）。

## 4. 年度檢視會議議程（每年一次，60 分鐘）

| 時間 | 項目 | 產出 |
|---|---|---|
| 10 分 | 現況更新：收入、支出、淨值、儲蓄率變化 | 三個數字的年變化 |
| 10 分 | 目標變動：有沒有新目標？既有目標的金額／年限要改嗎？ | 更新後的目標分層表 |
| 10 分 | 配置偏離：實際權重 vs 目標，是否觸發 5/25 | 再平衡指令（買賣金額） |
| 10 分 | 保障與負債：保單有無變動、利率有無調整、要不要提前還款 | 待辦清單 |
| 10 分 | 決策回顧：去年的決策**當時的理由**是否成立（不看結果看品質） | 保留／修正的規則 |
| 10 分 | 明年計畫：投入金額、自動化設定、下次檢視日期 | 一頁行動計畫 |

**回顧原則**：把「決策品質」與「結果好壞」分開評分。
好決策＋壞結果 ＝ 運氣，規則不改；壞決策＋好結果 ＝ 僥倖，規則要改。

## 5. 決策紀錄表（每次調整都留一筆）

| 欄位 | 內容 |
|---|---|
| 日期 | |
| 動作 | 買／賣／調整權重／新增目標 |
| 標的與金額 | |
| 當時理由 | 一句話，不能寫「因為會漲」 |
| 依據的假設 | 例如：報酬 6%、通膨 2%、五年後用錢 |
| 退出／修正條件 | 什麼事發生我就改變主意 |
| 情緒溫度（1–10） | 高於 7 分時，強制隔 24 小時再執行 |

## 6. 自動化清單（降低意志力成本）

1. 薪轉當日自動轉出投入金額（先支付自己）。
2. 緊急金放獨立帳戶，不與日常帳戶混用。
3. 定期定額扣款設定好之後，不要每月手動決定。
4. 年度檢視日寫進行事曆（例如每年 1 月第一個週末）。
5. 停用即時報價推播；只在檢視日看帳。
