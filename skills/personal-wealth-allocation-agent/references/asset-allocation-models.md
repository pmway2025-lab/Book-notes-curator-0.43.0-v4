# 資產配置模型與參數

本檔是 `personal-wealth-allocation-agent` 階段三（配置設計）的參數來源。
所有數字都是**規劃用假設**，不是預測。使用時必須向使用者明示假設值。

---

## 1. 生命週期股債比

三種常見起手式，依風險屬性擇一，再用下方調整因子微調：

| 法則 | 公式（股票權重） | 適用 |
|---|---|---|
| 100 法則 | 100 − 年齡 | 保守、退休近在眼前 |
| 110 法則 | 110 − 年齡 | 一般預設 |
| 120 法則 | 120 − 年齡 | 積極、距退休 20 年以上、收入穩定 |

**調整因子（每項 ±5～10 個百分點，總調整不超過 ±20）**：

| 條件 | 方向 |
|---|---|
| 收入高度穩定（公職、軍職、長約） | 股票 +5～10 |
| 收入隨專案波動、接案、業務獎金為主 | 股票 −5～10 |
| 有 12 個月以上緊急金 | +5 |
| 緊急金不足 6 個月 | 先補金，不談加碼 |
| 有房貸且月付 > 收入 1/3 | −5～10 |
| 扶養人數多、單一收入來源 | −5～10 |
| 明確表達「−30% 會出場」 | −10，並改為分批投入 |
| 5 年內有大額支出（購屋、創業） | 該筆資金整包移出成長層 |

**下滑路徑（glide path）**：距目標年限每減少 5 年，股票權重下調 5–10 個百分點；
退休前 5 年應完成「未來 3–5 年生活費」的現金／短債水位建置。

## 2. 核心衛星（Core–Satellite）

- **核心 80%+**：低成本、廣泛分散、長期持有。用途是「取得市場報酬」。
  典型：全球或美國大盤股票型 ＋ 投資等級債（或定存／短債替代）。
- **衛星 ≤ 20%**：主題、單一國家、產業、個股、加密資產等。
  每一筆衛星部位必須寫下三件事，寫不出來就不要買：
  1. 買進理由（為什麼這個機會存在？誰在賣給我？）
  2. 退出條件（什麼事發生我就承認錯了？）
  3. 最大可承受虧損（歸零時對總計畫的影響）
- **衛星紀律**：衛星部位不因為漲了就升格成核心；再平衡時一併算進權重。

## 3. 風險平價的可用概念（不必真的做槓桿版本）

一般人可以借用的只有一個核心觀念：**權重要看風險貢獻，不是看金額**。
一個 60 股／40 債的組合，波動幾乎全部來自股票那 60%。因此：

- 「我有分散」不等於「風險有分散」——五檔科技 ETF 是一個部位，不是五個。
- 檢查集中度時，看的是**風險來源**：產業、國家、貨幣、單一雇主（自家公司股票
  ＋薪水＋員工認股，是同一個風險）。
- 實務做法：列出「若這個風險來源出事，我的資產和收入會同時受影響嗎？」
  會的話，權重要往下砍。

## 4. 常見資產類別的角色

| 類別 | 在組合裡的功能 | 注意 |
|---|---|---|
| 全球／已開發市場股票 | 長期成長引擎 | 波動大，−40% 是歷史上發生過的常態 |
| 新興市場股票 | 分散、成長 | 波動更大，權重通常 ≤ 股票部位的 20% |
| 投資等級債／公債 | 降波動、危機時的緩衝 | 存續期越長，對利率越敏感 |
| 短債／定存／貨幣型 | 流動性與防守 | 是「不虧」不是「保值」，會被通膨侵蝕 |
| 不動產（自住） | 居住需求＋槓桿 | 對多數台灣家庭已是最大單一部位，配置時要計入 |
| 不動產（收益型／REITs） | 收益、部分分散 | 與股市相關性沒有想像中低 |
| 黃金／商品 | 極端情境對沖 | 無現金流，權重通常 ≤ 10% |
| 加密資產 | 高風險衛星 | 若要納入，權重 ≤ 5%，且視同可能歸零 |

## 5. 再平衡法則

| 方式 | 規則 | 優缺點 |
|---|---|---|
| 時間法 | 每年固定日期檢視並調回目標 | 簡單、可執行；可能錯過大偏離 |
| 門檻法（5/25） | 絕對偏離 5 個百分點，或相對偏離 25%，先到先觸發 | 較貼近風險，需要定期檢查 |
| 混合（建議） | 每年檢視一次＋門檻觸發時額外處理 | 兼顧紀律與風險 |
| 現金流再平衡 | 用新資金優先買入低配類別 | 免賣出、少稅費，**應為首選** |

5/25 範例：目標 60% 股票。絕對法在 55% 或 65% 觸發；相對法在
60×(1±25%) ＝ 45% 或 75% 觸發。取先達到者 → 實務上是 55%／65%。
小權重類別（例如目標 8%）則相對法先到：6%／10%。

## 6. 規劃用報酬與波動假設（保守版，僅供試算）

| 資產 | 名目年化報酬假設 | 常見最大回檔 |
|---|---|---|
| 全球股票 | 6–7% | −40%～−55% |
| 投資等級債 | 3–4% | −10%～−20% |
| 現金／短債 | 1–2% | ~0% |
| 通膨假設 | 2% | — |

**使用規則**：
1. 試算一律同時給「基準（上表）」與「悲觀（股票報酬砍到 3%、且前 3 年 −30%）」。
2. 不要用最近三年的報酬外推長期。
3. 實質報酬 ≈ 名目報酬 − 通膨；談退休金一定要用實質報酬。
4. 費用是確定的負報酬：總費用每年 1%，30 年約侵蝕最終資產 25% 上下。
   選工具時，費用率的優先級高於過去績效。

## 7. 提領階段（退休）

- **4% 法則**是起點不是保證：以退休首年提領年支出 ÷ 資產 ≦ 4%，逐年依通膨調整。
  台灣情境建議用 **3.0–3.5%** 較保守（壽命長、醫療支出、單一貨幣風險）。
- **FIRE 目標數** ＝ 年支出 ÷ 提領率。年支出 72 萬、提領率 3.5% → 約 2,057 萬。
- **順序報酬風險**：退休前後 5 年的大跌最致命。對策是退休前備妥
  3–5 年生活費的現金／短債水位，跌市時先動這桶，不賣股。
- 台灣可扣抵的既有現金流（勞保年金、勞退月退、軍公教退俸）應先估算，
  再用投資部位補差額——**先算缺口，再算要準備多少**。
